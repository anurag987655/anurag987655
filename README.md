## 📡 TDA for Wireless Signal Analysis

An ongoing research-oriented project exploring **Topological Data Analysis (TDA)** for wireless signal analysis.

The project investigates whether topological features can help distinguish between clean and heavily interfered/jammed communication signals, including scenarios where conventional energy-based approaches become less reliable.
